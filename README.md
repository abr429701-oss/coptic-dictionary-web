# ⲭⲏⲙⲓ — القاموس القبطي

قاموس قبطي بحيري سريع بواجهة عربية مستوحاة من صفحة Apps Script المرجعية. يحافظ الموقع على فهرس GitHub المجزّأ الذي يتضمن أكثر من 16 ألف مدخل، ويضيف إليه ملفات الصوت وبيانات النوع والأصل المتاحة من جدول المرجع. لا يحمّل المتصفح القاموس كاملًا عند البحث؛ بل يجلب فهرسًا صغيرًا ثم تفاصيل النتيجة عند الحاجة.

## وظائف الواجهة

- بحث بالقبطية والعربية والإنجليزية والفرنسية والألمانية، مع اقتراحات أثناء الكتابة.
- عرض النتائج بطاقة واحدة في كل مرة، وزر لعرض المعنى التالي.
- لوحة مفاتيح قبطية، تاريخ قبطي وميلادي، وروابط التسجيل والتعلّم.
- مشغل صوت ببدء/إيقاف، شريط تقدم، تغيير مستوى الصوت وكتمه، وتنزيل الملف عندما يتوفر.
- نسخ المعنى وإنشاء/مشاركة بطاقة نتيجة بصيغة صورة.
- نافذة إشعارات وشارة للرسائل الجديدة مع تحديث دوري كل دقيقة.
- حدّ بحث محلي: بحثان قبل دعوة التسجيل، ويُحفظ العداد في `localStorage` على الجهاز فقط. لا يطلب الموقع إذنًا ولا يجلب عنوان IP ولا يرسله أو يخزّنه.

## البيانات والخصوصية

- `scripts/sheet_to_json.py` يحدّث القاموس الأساسي من Google Sheets.
- `scripts/download_appscript_audio.py` يزامن ملفات الصوت العامة التي ترتبط بصفوف القاموس إلى `audio-appscript/` (ويتخطّى الملفات الموجودة).
- `scripts/enrich_appscript_data.py` يضيف حقول المصدر المرجعي والروابط الصوتية إلى الكلمات المطابقة، ويضيف الصفوف التي لا توجد في القاموس الأساسي.
- خط Naqlun / Gabriel Arshiagelos المرفوع للمشروع يطبّق على محارف القبطية فقط؛ يظل خط العربية منفصلًا.
- الإشعارات تُقرأ من تبويب `bot` عبر نطاق العمود `B2:B` فقط. لا يقرأ الموقع أعمدة المعرّفات أو الأسماء ولا تبويب IP.
- التسجيل يفتح صفحة التسجيل الخارجية كما في المرجع؛ حدّ البحث محلي وغير موثّق من الخادم، ولذلك يمكن للمستخدم تجاوزه بمسح بيانات الموقع. الضغط على التسجيل يعيد العداد المحلي.

## البناء والاختبار

```bash
npm test
npm run build
npm start
```

يفتح الخادم المحلي على `http://localhost:8000`.

للمعاينة التطويرية التي تعيد البناء تلقائيًا وتحدّث الصفحة المفتوحة عند تعديل ملفات المشروع:

```bash
npm run dev
```
