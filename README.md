# القاموس القبطي البحيري — نسخة الموقع

موقع إلكتروني ثابت (بدون خادم) يعمل على **GitHub Pages**، وهو نسخة من [بوت Telegram](https://github.com/abr429701-oss/coptic-dictionary-bot) بنفس منطق البحث وبنفس رسائله وأزراره، لكن داخل محادثة على صفحة ويب.

## ما الذي ينقله الموقع من البوت

- **نفس محرك البحث بالضبط:** منقول حرفيًا من Worker البوت (`src/index.js`). جرى التحقق منه بمقارنة ردود البوت الأصلي بردود الموقع على أكثر من 2,500 استعلام مختلف وحوالي 25 ألف مقارنة (كلمات كاملة، بدايات كلمات، همزات وتشكيل، عربي وقبطي وإنجليزي وفرنسي وألماني وIPA…) بدون أي اختلاف.
- البحث بالقبطية والعربية والإنجليزية والفرنسية والألمانية والنطق، مع تطبيع الألف والياء والتشكيل والجنكيم.
- الكلمة المطابقة تظهر مباشرة بحقولها: **الكلمة / المعنى / النوع / الأصل**، ومعانيها الأخرى خلف زر «اعرض المزيد من الكلمات» (كل معنى مرة واحدة).
- من غير مطابقة تامة: اقتراحات بالكلمات التي تبدأ بما كتبته، 10 في الصفحة، مع «السابق/التالي».
- واجهة الرسائل تتبع لغة البحث (عربي/English/Français/Deutsch) كما في البوت، ونوع الكلمة وأصلها يُترجمان.
- **النطق:** زر صوتي تحت كل نتيجة. المصدر نفسه الذي يستخدمه البوت (ملفات `<رقم الكلمة>.ogg` من فرع `audio` في مستودع البوت)، ومعه تسجيلات «Matthew / IPA» المضمّنة هنا. وإن لم يوجد ملف للكلمة يُقرأ نطقها بصوت المتصفح (بديل Google TTS في البوت).
- `/start` و`/help` تعملان في خانة الكتابة، وأي أمر آخر يعطي نفس رد البوت. زر «؟» لعرض المساعدة، وزر ⟲ لمسح المحادثة.
- رابط مباشر لبحث جاهز: `https://<المستخدم>.github.io/<المستودع>/?q=ماء`
- **مزامنة القاموس من Google Sheets** كل 30 دقيقة عبر GitHub Actions (نفس الشيت وسكربت التحويل `scripts/sheet_to_json.py` من البوت)، مع الأرقام الدائمة للكلمات (`data/word_ids.json`).

## ما لا ينتقل (لأنه خاص بـ Telegram نفسه)

هذه وظائف إدارة تعتمد على حسابات Telegram وقاعدة مستخدمين وخادم، ولا معنى لها في موقع ثابت: تسجيل المستخدم باسمه الثلاثي، لوحة الأدمن، `/broadcast`، تسجيل النطق من داخل Telegram عبر `/record` ومزامنتها مع Drive، عدّاد الطلبات `/usage`، والبحث Inline من أي محادثة. كذلك التسجيلات الصوتية التي حفظها الأدمن داخل Telegram محفوظة كمعرّفات خاصة بـ Telegram ولا يمكن تشغيلها من موقع؛ الموقع يستخدم بدلها ملفات الصوت العامة.

> البحث بالكلمات اليونانية موقوف عمدًا في البوت الأصلي (عمود اليونانية للعرض فقط)، ولذلك نُقل كما هو.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثلًا `coptic-dictionary-web`) وارفع محتويات هذا المجلد إلى فرع `main`.
2. من **Settings ← Pages** اختر **Source: GitHub Actions**.
3. سيعمل workflow **Deploy dictionary website** تلقائيًا ويعطيك رابط الموقع. يمكن تشغيله يدويًا من **Actions ← Deploy dictionary website ← Run workflow**.

الـ workflow ينزّل الشيت ويحوّله إلى `data/dictionary.json`، ويشغّل الاختبارات، ويحفظ التغيير إن وُجد، ثم ينشر. أما التشغيل المجدول فلا ينشر إلا إذا تغيّر القاموس فعلًا.

> ليعمل التنزيل من الشيت يجب أن يكون مشاركًا بصيغة «أي شخص لديه الرابط»، كما في البوت. لتغيير الشيت عدّل `SHEET_ID` داخل `scripts/sheet_to_json.py`.

## التشغيل والاختبار محليًا

```bash
npm start        # ثم افتح http://localhost:8000
npm test         # اختبارات المحرك
```

## الإعدادات (`js/config.js`)

| الإعداد | الوظيفة |
|---|---|
| `AUDIO_BASE_URL` | مكان ملفات النطق `<id>.ogg`. الافتراضي فرع `audio` في مستودع البوت العام. لو نسخت الملفات إلى مستودعك ضع مسارها هنا. |
| `HUMAN_AUDIO` / `HUMAN_AUDIO_URL` | تسجيلات Matthew/IPA المضمّنة في `audio-human/` وتُفضَّل على النطق الافتراضي. إن أضفت ملفات جديدة أضف رقمها إلى `audio-human/manifest.json`. |
| `SPEECH_FALLBACK` | قراءة النطق بصوت المتصفح حين لا يوجد ملف صوتي. |

## هيكل المشروع

```
index.html            الصفحة
css/style.css         التصميم (فاتح/داكن، يعمل على الهاتف)
js/engine.js          محرك البحث (منقول من Worker البوت)
js/app.js             واجهة المحادثة وتشغيل الصوت
js/field-translations.js  ترجمات النوع والأصل (من البوت)
js/config.js          الإعدادات
data/                 dictionary.json و word_ids.json
audio-human/          تسجيلات مضمّنة
scripts/sheet_to_json.py  مزامنة الشيت
.github/workflows/deploy.yml  النشر والمزامنة
```
